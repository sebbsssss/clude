Portable Memory Protocol

Verify a memory.
Don't trust us.

Every memory Clude stores gets a cryptographic fingerprint committed to Solana. Paste any memory ID and check, yourself, that it is the original and has not been altered. The proof lives on a public chain, not in our database.

Try one: clude-11db4f18 clude-11f87d9f clude-6983ed42
How verification works
01
Fingerprint
At write time, a SHA-256 hash is taken over the memory's content and context. The same memory always produces the same hash.
02
Commit on-chain
That fingerprint is committed to the Solana blockchain. The proof is public. The content stays off-chain.
03
Recompute & compare
To verify, Clude recomputes the fingerprint and compares it to the chain. Match, and it is provably the original. Change one character, and the proof breaks.
