03
The data & method

Machine-checkable answers from a frozen public dataset. No cherry-picking, no adjustable ground truth.

Dataset
bigquery-public-data.crypto_solana_mainnet_us
Snapshot frozen 2025-03-31 — immutable ground truth. Tables: Blocks, Transactions, Accounts, Tokens.
Model
claude-haiku-4-5
Same model, same system prompt — only difference is Clude's recalled memories in context. No fine-tuning. No prompt engineering advantage.
Ground truth
Exact values from BigQuery: slot numbers, block times (UTC), validator pubkeys, transaction counts. Answers are string-matched, not LLM-judged.

Solana data on BigQuery ↗
Scoring rule
Abstaining ("I don't know" / "not enough information") counts as not hallucinating — it is the correct behavior when memory is absent. Hallucination = confident wrong answer. Clude is optimised for grounded-or-abstain, not for guessing.
